# Frequently Asked Questions (FAQ)

**Q: What is Split Soul?**
A: A Chrome extension with multi-agent companions that run locally using Chromes Built-in AI.

**Q: How do I install it?**
A: npm install npm run build chrome://extensions Load unpacked select dist/.

**Q: How do I start the app?**
A: Run `npm install` then `npm run dev`.

**Q: Where is data stored?**
A: Locally in IndexedDB via Dexie. No server calls by default.

**Q: Do I need an API key?**
A: Not required for Chromes Built-in AI.

**Q: How to allow in Incognito?**
A: Currently we are not suppourting in incognito.

**Q: How do I reset data?**
A: Use Settings Tab (Reset Database / Clear Chats / Clear Actions / Clear Activities).

**Q: How do I contribute?**
A: See `docs/contributing.md`.
